# Tutor curriculum mapping

GEF lessons map to learning objectives, not to one textbook page.

Use stable lesson IDs and rule IDs when connecting a course, unit, standard, or external LMS assignment to GEF. The selected reading material can vary as long as the content layer has suitable reviewed evidence for the same lesson and rules.

A mapping may record an external provider/course/unit identifier, GEF lesson IDs, optional rule IDs, language tags, proficiency range, version, and review state.

`gef-content` remains responsible for showing which works and editions contain suitable lesson examples. This allows one grammar lesson to use GEF-curated examples, a school-selected book, a tutor-selected licensed work, or another eligible work without duplicating linguistic truth in this repository.

LMS course IDs, line-item IDs, and book IDs are integration metadata. They must not replace the stable lexicon lesson and rule identifiers.
