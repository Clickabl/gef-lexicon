# Shared reusable entities

`entities/index.json` is canonical source truth. New `ent_`, `lbl_`, `bio_` and `rel_` UUIDv4 IDs are allocated by the synchronized Server authoring journal, never by these functions or from labels. Existing lexical/nameGraph/public work and edition identities remain intact. The initial revision1 empty source is a compatibility foundation, not completed catalog migration. TODO-LEXICON-ENTITY-REGISTRY-20261013 remains open through actual source admission and cross-repository integration.

The pure validator preserves exact text, actual declared language, review and source evidence. Preferred names use exact/compatible scripts, English, then canonical source text; fallback never acquires the requested language. Names/aliases may have unknown language. Translation status is separate from review. Reviewed lookup admits approved labels; beta additionally admits candidates with their actual state. Search retains distinct matching identities and stable IDs after renaming. Latin diacritic fallback ranks below exact spelling; other scripts retain their own marks.

Short and long biographies are independent supplied source fields. Work-scoped documentary portraits require the matching work context and never become invented universal biographies. Missing biography stays absent. `research_notes` is private source material and is omitted from public projection and SQLite. Existing source birth_date/death_date compatibility text stays exact; canonical birth/death uses the byte-checked owning Content temporal schema and semantic validator. No calendar conversion is implemented here.

`validate-entity-registry.mjs` and `compile-entity-registry.mjs --check` are read-only owning writer checks. Explicit `compile-entity-registry.mjs --output staging/lexi/entities-v1` writes real normalized SQLite, exact-ID JSON, immutable hash receipt and atomic manifest. Every owning reference, redirect, external identity and source reference is validated; cycles/orphans/reused aliases are rejected. The public namespace is already on the Lexicon receiver allowlist. Raw source entities/ is excluded. Full source is preserved; exceeding a documented byte bound fails rather than silently truncating.

`sync-entity-temporal-contract.mjs --source /path/to/gef-content [--check]` embeds the exact owning schema and validator for pure consumers and checks source hashes. Do not edit the generated temporal module. Server mirrors all runtime dependencies byte-for-byte; source writes still run these owning CLI checks.

Run `npm run validate:entities`, the full repository validation, then compile/publish and verify actual public bytes. Publication does not approve facts or complete the App/Content/Server integration.

Public manifest registry/sources/sqlite entries each carry immutable path, byte size and SHA256; package_sha256 includes registry and citation hashes so bibliography correction changes the package even when entity labels stay unchanged. Sources are only the admitted referenced bibliography plus parent closure, preserving real titles/URLs/licenses/external IDs and omitting private note/content_source_provenance. Every published source_ref resolves offline.

Structured relationships are independently identified and reviewed evidence facts. Closed relationship kinds separate birthplace/death place, association/citizenship/cultural origin, language of work, movement/occupation, membership and tradition attribution; their target IDs resolve to actual appropriately typed entities, following retained redirects without rewriting source targets. Known/approximate claims require source references. Optional periods reuse the Content date contract and chronology; exact historical context can have unknown source language. No relationship or nationality is inferred from a caption, birthplace or attribution. Public SQLite schema version2 includes normalized relationship/target foreign keys; immutable package identity includes the DB schema version, and manifest counts include relationships.

`validatePublicEntitySources` is the portable owning boundary for offline citation JSON, independent of private bibliography/checkouts. It admits the exact compiler whitelist, checks parent cycles/orphans and every entity/temporal source ref, preserves actual optional missing/empty fields and rejects private note/raw provenance fields. Public registry/citations each remain8MiB; actual SQLite must fit16MiB or publication fails before immutable install/pointer mutation.
